VTOL Strict Precision Landing Gate

A custom embedded ArduPilot Lua script for QuadPlane VTOL aircraft enforcing a strict two-phase precision landing. It freezes altitude below 7 meters until the craft is centered within 35 cm of the ground beacon—eliminating landing drift completely.

EXECUTIVE OVERVIEW

What Is This Project?

Standard autonomous drone landing algorithms continue descending even when wind gusts or sensor latency drift the aircraft off-target. In high-precision operations (such as deck landing or wireless charging pads), descending while off-center can cause catastrophic misses.

This custom Lua script runs directly inside the Pixhawk flight controller, taking real-time control of descent rates and waypoint steering. It guarantees touchdown accuracy within 35 cm.

🎯

Two-Phase Logic

Free approach above 7 m; strict altitude freeze below 7 m until perfectly centered.

CONTROL ARCHITECTURE

Two-Phase Landing State Machine

> 7.0 meters

Phase 1 — Free Approach & Steering

Aircraft steers toward target using proportional PLND_XY_GAIN while descending at standard speed. Allows rapid approach from altitude.

≤ 7.0 meters

Phase 2 — Strict Precision Gate (Altitude Freeze)

Descent speed set to 0 (altitude locked) unless XY offset ≤ 35 cm. If drone drifts or target is lost, altitude holds until re-centered.

EMBEDDED LUA IMPLEMENTATION

Key Code Architecture

vtol_strict_landing.lua — Phase 2 Descent Gate Lua 5.3 Embedded 
-- Below 7m: Only allow descent when craft is centered over beacon
if xy_dist <= PLND_DESCENT_RADIUS:get() then

    -- Centered within 35cm: resume final descent rate
    vehicle:set_land_descent_rate(Q_LAND_FINAL_SPD:get())
    gcs:send_text(MAV_SEVERITY.INFO, "PLND: CENTERED - DESCENT ENABLED (<7m)")

else
    -- Off-center or drifting: freeze altitude instantly
    vehicle:set_land_descent_rate(0)
    gcs:send_text(MAV_SEVERITY.INFO,
        string.format("PLND: HOLD ALT (XY=%.2fm <7m)", xy_dist))
end

-- Protected 10 Hz Execution Wrapper using pcall
local function protected_wrapper()
    local ok, err = pcall(update)
    if not ok then
        gcs:send_text(MAV_SEVERITY.ERROR, "PLND ERROR: " .. err)
        return protected_wrapper, 1000   -- Retry in 1s on error
    end
    return protected_wrapper, 100        -- Normal 10 Hz tick rate
end
RUNTIME CONFIGURATION

GCS ArduPilot Parameters

Parameter Default Value Description
PLND_XY_GAIN 2.5 Amplifies XY steering correction. Higher = more aggressive response.
PLND_DESCENT_RAD 0.35 m Max allowable XY offset before Phase 2 descent is permitted.
PLND_LOST_HOLD 1 Freeze altitude when beacon target is lost below 7 meters.
PLND_ENABLED 1 Master enable flag. Exits immediately if set to 0.
